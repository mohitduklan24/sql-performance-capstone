# SQL Performance Capstone

A benchmarking and query optimization suite designed to analyze database bottlenecks, optimize query execution paths, and evaluate index efficiency.

## Overview
- Diagnose inefficient `JOIN` and subquery execution plans.
- Provide before-and-after performance metrics using `EXPLAIN ANALYZE`.
- Enforce schema constraints and clean relational models.

## Quickstart & Verification
1. Clone the repository: `git clone https://github.com/mohitduklan24/sql-performance-capstone.git`
2. Run benchmark suites: `node scripts/run_benchmarks.js`
3. Inspect generated query plans in `/docs/benchmarks/`.
